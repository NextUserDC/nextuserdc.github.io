## Tema 1: Estructura Atómica

### 1.1 Modelo atómico

**Modelo de Bohr:**
- Núcleo con protones (+) y neutrones (neutros)
- Electrones (-) giran en órbitas/capas
- Cada órbita tiene una energía específica

**Tabla periódica:**
- **Número atómico (Z)** = número de protones = número de electrones (en átomo neutro)
- **Número másico (A)** = protones + neutrones
- **Neutrones** = A - Z

**Isótopos:** Mismo Z, diferente A (mismos protones, distintos neutrones)

### 1.2 Configuración electrónica

**Capas y subcapas:**
```
Capa 1 (K): 1s       → 2 electrones
Capa 2 (L): 2s, 2p   → 8 electrones
Capa 3 (M): 3s, 3p, 3d → 18 electrones
Capa 4 (N): 4s, 4p, 4d, 4f → 32 electrones
```

**Regla de llenado:** 1s → 2s → 2p → 3s → 3p → 4s → 3d → 4p...

**Regla de octeto:** Los átomos tienden a tener 8 electrones en su última capa (estabilidad)

### 1.3 Período y Grupo

| Concepto | Significado |
|----------|-------------|
| **Período** | Fila horizontal → número de capas |
| **Grupo** | Columna vertical → propiedades similares |
| **Metales** | Grupos 1-12 +部分os del 13-16 |
| **No metales** | Grupos 15-18 |
| **Metaloides** | B, Si, Ge, As, Sb, Te |

## Tema 2: Enlaces Químicos

### 2.1 Enlace iónico

**¿Cuándo ocurre?** Metal + No metal

**Mecanismo:** Transferencia de electrones
- Metal pierde electrones → catión (+)
- No metal gana electrones → anión (-)
- Atracción electrostática = enlace

**Ejemplo: NaCl**
```
Na → Na⁺ + e⁻  (pierde 1 electrón)
Cl + e⁻ → Cl⁻  (gana 1 electrón)
Na⁺ + Cl⁻ → NaCl
```

**Propiedades:**
- Alto punto de fusión
- Conducen electricidad en solución
- Solubles en agua
- Frágiles (cristalinos)

### 2.2 Enlace covalente

**¿Cuándo ocurre?** No metal + No metal

**Mecanismo:** Compartición de electrones

**Tipos:**
- **Simple:** 1 par de electrones compartidos (H₂)
- **Doble:** 2 pares (O₂)
- **Triple:** 3 pares (N₂)

**Ejemplo: H₂O**
```
O tiene 6 electrones de valencia
Necesita 2 más para completar octeto
Cada H aporta 1 electrón
O comparte 2 electrones (1 con cada H)
Resultado: H-O-H (2 enlaces simples)
```

### 2.3 Enlace metálico

**¿Cuándo ocurre?** Metal + Metal

**Mecanismo:** Electrones deslocalizados (mar de electrones)
- Los átomos de metal ceden electrones a una "nube" compartida
- Los electrones se mueven libremente

**Propiedades:**
- Buenos conductores del calor y electricidad
- Maleables y ductiles
- Brillantes
- Alto punto de fusión (generalmente)

### 2.4 Polaridad

**Enlace polar:** Diferencia de electronegatividad > 0.4
- Un átomo atrae más los electrones (δ-)
- El otro queda con carga parcial positiva (δ+)

**Enlace no polar:** Diferencia < 0.4
- Electrones compartidos equitativamente

**Molécula polar:** Asimetría en la distribución de cargas
- Ej: H₂O (forma de V, asimétrica)

**Molécula no polar:** Simétrica
- Ej: CO₂ (lineal, simétrica)

## Tema 3: Reacciones Químicas

### 3.1 Tipos de reacciones

| Tipo | Descripción | Ejemplo |
|------|-------------|---------|
| **Síntesis** | A + B → AB | 2H₂ + O₂ → 2H₂O |
| **Descomposición** | AB → A + B | 2H₂O → 2H₂ + O₂ |
| **Sustitución simple** | A + BC → AC + B | Zn + CuSO₄ → ZnSO₄ + Cu |
| **Doble sustitución** | AB + CD → AD + CB | AgNO₃ + NaCl → AgCl + NaNO₃ |
| **Combustión** | Hidrocarburo + O₂ → CO₂ + H₂O | CH₄ + 2O₂ → CO₂ + 2H₂O |
| **Redox** | Transferencia de electrones | Zn → Zn²⁺ + 2e⁻ |

### 3.2 Estequiometría

**Masa molar:**
- Un mol = 6.022 × 10²³ partículas (Número de Avogadro)
- Masa molar = masa de 1 mol en gramos
- Ej: H₂O = 2(1) + 16 = 18 g/mol

**Conversiones:**
```
masa (g) ↔ moles ↔ partículas
     ÷ masa molar    × Avogadro
     × masa molar    ÷ Avogadro
```

**Relaciones estequiométricas:**
1. Escribir ecuación balanceada
2. Calcular moles de cada sustancia
3. Usar coeficientes como proporción

**Ejemplo:**
> ¿Cuántos gramos de O₂ se necesitan para quemar 16 g de CH₄?
> CH₄ + 2O₂ → CO₂ + 2H₂O
> CH₄: 16 g ÷ 16 g/mol = 1 mol
> O₂ necesita: 2 × 1 = 2 mols
> O₂ masa: 2 × 32 = 64 g

### 3.3 Concentraciones

**Molaridad (M):**
```
M = moles de soluto / litros de solución
```

**Dilución:**
```
M₁V₁ = M₂V₂
```

## Temo 4: Ácidos, Bases y Sales

### 4.1 Ácidos

**Definición (Arrhenius):** Sustancia que libera H⁺ en agua
**Definición (Brønsted):** Donador de protones (H⁺)

**Propiedades:**
- Sabor agrio (limón, vinagre)
- pH < 7
- Cambian indicadores (rojo con fenolftaleína → transparente)
- Reaccionan con metales para producir H₂
- Reaccionan con bases para formar sal + agua

**Ejemplos:** HCl (clorhídrico), H₂SO₄ (sulfúrico), HNO₃ (nítrico)

### 4.2 Bases

**Definición (Arrhenius):** Sustancia que libera OH⁻ en agua
**Definición (Brønsted):** Aceptor de protones (H⁺)

**Propiedades:**
- Sabor amargo
- pH > 7
- Cambian indicadores (transparente con fenolftaleína → rosa)
- Sosas al tacto
- Reaccionan con ácidos para formar sal + agua

**Ejemplos:** NaOH (hidróxido de sodio), Ca(OH)₂ (calcio)

### 4.3 pH

```
pH = -log[H⁺]

pH < 7 → Ácido
pH = 7 → Neutro
pH > 7 → Básico

Cada unidad de pH = cambio de 10× en [H⁺]
```

### 4.4 Neutralización

```
Ácido + Base → Sal + Agua
HCl + NaOH → NaCl + H₂O
```

### 4.5 Sales

- Producto de la neutralización
- Combinación de catión (del ácido) + anión (de la base)
- Ej: NaCl = Na⁺ (base) + Cl⁻ (ácido)

## Resumen de Fórmulas Clave

```
ATÓMICO:
- Z = protones = electrones
- A = protones + neutrones
- Neutrones = A - Z

ENLACE:
- Iónico: metal + no metal
- Covalente: no metal + no metal
- Metálico: metal + metal

ESTEQUIOMETRÍA:
- Moles = masa / masa molar
- M₁V₁ = M₂V₂ (dilución)

pH:
- pH = -log[H⁺]
- pH + pOH = 14
```
