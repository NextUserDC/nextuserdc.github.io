## Estructura por Ejes

### Eje 1: Números (26% ≈ 17 preguntas)

#### 1.1 Operaciones con números reales

**Suma y resta de fracciones:**
```
a/b + c/d = (ad + bc) / bd
a/b - c/d = (ad - bc) / bd
```

**Ejemplo:**
```
3/4 + 2/5 = (3×5 + 2×4) / (4×5) = (15+8)/20 = 23/20 = 1 3/20
```

**Multiplicación y división de fracciones:**
```
a/b × c/d = (a×c) / (b×d)
a/b ÷ c/d = a/b × d/c = (a×d) / (b×c)
```

**Potencias:**
```
a^n × a^m = a^(n+m)
a^n / a^m = a^(n-m)
(a^n)^m = a^(n×m)
a^0 = 1 (para a ≠ 0)
a^(-n) = 1/a^n
```

**Raíces cuadradas:**
```
√(a×b) = √a × √b
√(a/b) = √a / √b
√(a²) = |a|
```

**Ejemplo resuelto:**
> Calcular: √(18) + √(8) - √(2)
> √18 = √(9×2) = 3√2
> √8 = √(4×2) = 2√2
> √2 = √2
> Resultado: 3√2 + 2√2 - √2 = 4√2

#### 1.2 Porcentajes y tasas

**Fórmula del porcentaje:**
```
Valor final = Valor inicial × (1 ± tasa/100)
```

**Aumento:** Vf = Vi × (1 + t/100)
**Descuento:** Vf = Vi × (1 - t/100)

**Ejemplo:**
> Un producto cuesta $50.000 con 20% de descuento.
> Precio final = 50.000 × (1 - 20/100) = 50.000 × 0.8 = $40.000

**Interés simple:**
```
I = C × r × t
Cf = C × (1 + r×t)
```
Donde C=capital, r=tasa, t=tiempo

**Interés compuesto:**
```
Cf = C × (1 + r)^t
```

#### 1.3 Proporcionalidad

**Directa:** y = k×x (si x aumenta, y aumenta)
**Inversa:** y = k/x (si x aumenta, y disminuye)

**Ejemplo:**
> 5工人 producen 20 piezas en 8 horas. ¿Cuántas producen 8 trabajadores en 6 horas?
> Relación: (trabajadores × horas) / piezas = constante
> (5 × 8) / 20 = 2
> (8 × 6) / 2 = 24 piezas

### Eje 2: Álgebra (29% ≈ 19 preguntas)

#### 2.1 Expresiones algebraicas

**Productos notables:**
```
(a + b)² = a² + 2ab + b²
(a - b)² = a² - 2ab + b²
(a + b)(a - b) = a² - b²
(a + b)³ = a³ + 3a²b + 3ab² + b³
```

**Factorización:**
```
Común: ax + ay = a(x + y)
Diferencia cuadrada: a² - b² = (a+b)(a-b)
Trinomio cuadrado: a² + 2ab + b² = (a+b)²
```

#### 2.2 Ecuaciones

**Ecuación lineal (1er grado):**
```
ax + b = 0 → x = -b/a
```

**Ecuación cuadrática (2do grado):**
```
ax² + bx + c = 0

Fórmula general: x = (-b ± √(b²-4ac)) / (2a)

Discriminante (Δ = b²-4ac):
- Δ > 0 → 2 soluciones reales
- Δ = 0 → 1 solución real (doble)
- Δ < 0 → sin solución real
```

**Ejemplo resuelto:**
> 2x² - 5x + 3 = 0
> a=2, b=-5, c=3
> Δ = 25 - 24 = 1 > 0
> x = (5 ± 1) / 4
> x₁ = 6/4 = 3/2
> x₂ = 4/4 = 1

**Sistemas de ecuaciones:**
```
Método de sustitución:
1. Despejar una variable de una ecuación
2. Sustituir en la otra
3. Resolver

Método de igualación:
1. Despejar la misma variable en ambas
2. Igualar las expresiones
3. Resolver

Método de eliminación (sumar/restar):
1. Multiplicar para que un coeficiente sea igual
2. Sumar o restar las ecuaciones
3. Resolver
```

**Ejemplo (eliminación):**
```
2x + 3y = 7
4x - 3y = 5
─────────────
6x = 12 → x = 2
Sustituir: 2(2) + 3y = 7 → 3y = 3 → y = 1
```

#### 2.3 Funciones

**Función lineal:** f(x) = mx + b
- m = pendiente (sube o baja la recta)
- b = corte con el eje Y

**Función cuadrática:** f(x) = ax² + bx + c
- Si a > 0 → parábola abre hacia arriba (mínimo)
- Si a < 0 → parábola abre hacia abajo (máximo)
- Vértice: x = -b/(2a)

**Gráficas:**
- Lineal → recta
- Cuadrática → parábola
- Exponencial → curva que crece rápido

### Eje 3: Geometría (21% ≈ 13 preguntas)

#### 3.1 Figuras planas

**Triángulo:**
```
Área = (base × altura) / 2
Perímetro = suma de los 3 lados

Tipos:
- Equilátero: 3 lados iguales, 3 ángulos de 60°
- Isósceles: 2 lados iguales
- Escaleno: 3 lados distintos

Suma de ángulos internos = 180°
```

**Rectángulo:**
```
Área = base × altura
Perímetro = 2(base + altura)
Diagonal = √(base² + altura²)
```

**Círculo:**
```
Área = π × r²
Perímetro = 2 × π × r = π × d
Área de sector = (θ/360) × π × r²
```

#### 3.2 Teorema de Pitágoras

```
En triángulo rectángulo:
a² + b² = c²
donde c = hipotenusa (lado más largo)

Para encontrar un lado:
- Hipotenusa: c = √(a² + b²)
- Cateto: a = √(c² - b²)
```

**Ejemplo:**
> Un triángulo rectángulo tiene catetos de 3 y 4. ¿Cuál es la hipotenusa?
> c = √(9 + 16) = √25 = 5

#### 3.3 Semejanza y congruencia

**Semejanza:** Figuras con igual forma pero diferente tamaño
- Ángulos iguales
- Lados proporcionales
- Razón de semejanza = k

**Congruencia:** Figuras iguales en forma y tamaño
- Lados iguales
- Ángulos iguales

#### 3.4 Trigonometría básica (ángulos agudos)

```
sen(θ) = opuesto / hipotenusa
cos(θ) = adyacente / hipotenusa
tan(θ) = opuesto / adyacente
```

**Valores especiales:**
| Ángulo | sen | cos | tan |
|--------|-----|-----|-----|
| 30° | 1/2 | √3/2 | 1/√3 |
| 45° | √2/2 | √2/2 | 1 |
| 60° | √3/2 | 1/2 | √3 |

### Eje 4: Probabilidad y Estadística (24% ≈ 15 preguntas)

#### 4.1 Estadística descriptiva

**Media (promedio):**
```
x̄ = (x₁ + x₂ + ... + xₙ) / n
```

**Mediana:** Valor central (después de ordenar)
- Si n es impar: posición (n+1)/2
- Si n es par: promedio de posiciones n/2 y n/2+1

**Moda:** Valor que más se repite

**Rango:** Máximo - Mínimo

**Varianza:**
```
σ² = Σ(xᵢ - x̄)² / n
```

**Desviación estándar:**
```
σ = √(varianza)
```

**Ejemplo:**
> Datos: 2, 5, 5, 7, 11
> Media: (2+5+5+7+11)/5 = 6
> Mediana: 5 (posición 3)
> Moda: 5
> Rango: 11 - 2 = 9

#### 4.2 Probabilidad

**Definición:**
```
P(evento) = Casos favorables / Casos posibles
0 ≤ P ≤ 1
```

**Regla de la suma:**
```
P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
```

**Eventos independientes:**
```
P(A ∩ B) = P(A) × P(B)
```

**Eventos complementarios:**
```
P(A') = 1 - P(A)
```

**Ejemplo:**
> Se lanza un dado. ¿P(número par)?
> Casos favorables: {2, 4, 6} = 3
> Casos posibles: {1, 2, 3, 4, 5, 6} = 6
> P = 3/6 = 1/2

#### 4.3 Tablas de frecuencia

| Tipo | Qué mide |
|------|----------|
| Absoluta (fi) | Cuántas veces aparece |
| Relativa (fri) | fi / n |
| Acumulada (Fi) | Suma hasta ese valor |
| Relativa acumulada | Fri acumulada |

## Errores Comunes en M1

| Error | Cómo evitarlo |
|-------|---------------|
| Olvidar el signo al factorizar | Verifica expandiendo |
| Confundir √ con 2√ | √4 = 2, 2√4 = 4 |
| No considerar Δ < 0 | Si Δ < 0, no hay solución real |
| Error en products notables | Memoriza y verifica con números |
| Calcular mal porcentajes | Usa la fórmula, no hagas mental |
| Confundir media con mediana | Ordena antes de calcular mediana |
